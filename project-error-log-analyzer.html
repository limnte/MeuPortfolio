Error Log Analyzer

Uma ferramenta leve em C que extrai eventos de log e organiza as informações críticas de forma clara.

  • Problema
  • Solução
  • De onde vêm os logs
  • Por que C

Problema

Diagnosticar uma falha no sistema exige extrair os eventos de log e separar o que é crítico do restante.

Solução

O Error Log Analyzer lê e processa logs e permite analisar, filtrar e visualizar os erros do sistema. O filtro é por severidade: erros, avisos e eventos críticos.

De onde vêm os logs

A ferramenta lê os logs de eventos do Windows, obtidos com wevtutil, ou arquivos de log em um caminho informado por quem a usa.

Por que C

Foi escrita em C para usar pouca memória e executar rápido, o que combina com uma ferramenta leve e eficiente.
